# VerdictOS

An AI-powered startup intelligence platform that evaluates startup ideas through a virtual boardroom of specialized AI agents.

---

## What is VerdictOS?

VerdictOS helps founders validate startup ideas before investing time and resources.

Instead of relying on a single AI response, the platform uses multiple expert agents that analyze a startup from different perspectives and generate a final executive verdict.

---

## The Problem

Validating a startup idea usually requires:

- Market research
- Competitor analysis
- Customer research
- Financial planning
- Risk assessment
- Investor feedback

These activities are often time-consuming and expensive.

---

## The Solution

VerdictOS automates startup validation using a multi-agent architecture.

Each AI agent focuses on a specific business domain and provides independent insights before a final decision is made.

## Multi-Agent Workflow

1. User submits a startup idea
2. Research data is collected
3. AI agents analyze the idea
4. Debate engine compares viewpoints
5. Voting engine calculates consensus
6. CEO agent generates the final verdict

## Installation

### Clone Repository

```bash
git clone https://github.com/aakashk7092/VerdictOS.git
```

### Frontend

```bash
cd frontendAgent
npm install
npm run dev
```

### Backend

```bash
cd backendAgent
npm install
npm run dev
```

---

## Environment Variables

Create a `.env` file inside `backendAgent`.

```env
GEMINI_API_KEY=YOUR_API_KEY
TAVILY_API_KEY=YOUR_API_KEY
```
